# Task 2 - Decision Trees

## Objectif

Cette tâche vise à introduire les arbres de décision, un algorithme intuitif et puissant en machine learning supervisé pour les problèmes de classification et de régression.

## Contenu

- **Decision_Trees_Model.ipynb** : Notebook Jupyter contenant l'implémentation des arbres de décision
- **data/** : Dossier pour les jeux de données

## Concepts Couverts

1. **Théorie des arbres de décision** :
   - Structure d'un arbre de décision
   - Mesures d'impureté (Gini, Entropie)
   - Critères de séparation

2. **Implémentation pratique** :
   - Utilisation de scikit-learn
   - Entraînement de l'arbre
   - Pruning (élagage) pour éviter le sur-apprentissage

3. **Visualisation** :
   - Représentation graphique de l'arbre
   - Interprétation des règles de décision

4. **Évaluation du modèle** :
   - Accuracy et autres métriques
   - Validation croisée

## Résultats Attendus

À la fin de cette tâche, vous devriez être capable de :
- Comprendre le fonctionnement des arbres de décision
- Implémenter un arbre de décision avec scikit-learn
- Visualiser et interpréter l'arbre résultant
- Appliquer des techniques pour éviter le sur-apprentissage

## Instructions d'Utilisation

1. Placez votre jeu de données dans le dossier `data/`
2. Créez un notebook Jupyter pour l'implémentation
3. Suivez les concepts présentés dans ce README

## Notes

Les arbres de décision sont faciles à interpréter et peuvent gérer à la fois des données numériques et catégorielles sans avoir besoin de beaucoup de prétraitement.
