# Task 1 - Logistic Regression

## Objectif

Cette tâche vise à introduire la régression logistique, un algorithme fondamental pour les problèmes de classification binaire en machine learning supervisé.

## Contenu

- **Logistic_Regression_Model.ipynb** : Notebook Jupyter contenant l'implémentation du modèle de régression logistique
- **data/** : Dossier pour les jeux de données

## Concepts Couverts

1. **Théorie de la régression logistique** :
   - Fonction logistique (sigmoïde)
   - Probabilités et odds ratios
   - Maximum de vraisemblance

2. **Implémentation pratique** :
   - Utilisation de scikit-learn
   - Entraînement du modèle
   - Prédiction de probabilités

3. **Évaluation du modèle** :
   - Accuracy, Precision, Recall
   - Courbe ROC et AUC
   - Matrice de confusion

## Résultats Attendus

À la fin de cette tâche, vous devriez être capable de :
- Comprendre le concept de régression logistique
- Implémenter un modèle de régression logistique avec scikit-learn
- Évaluer la performance du modèle de classification
- Interpréter les courbes ROC et les métriques associées

## Instructions d'Utilisation

1. Placez votre jeu de données dans le dossier `data/`
2. Créez un notebook Jupyter pour l'implémentation
3. Suivez les concepts présentés dans ce README

## Notes

La régression logistique est particulièrement adaptée aux problèmes de classification binaire et constitue la base de nombreux modèles plus avancés.
