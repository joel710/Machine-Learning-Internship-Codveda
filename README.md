# Machine Learning Internship - Codveda

Bienvenue dans le dépôt du stage de Machine Learning chez Codveda. Ce projet est structuré en trois niveaux de difficulté croissante, chacun contenant plusieurs tâches pratiques.

## Structure du Projet

- **Level 1 - Basic**: Tâches fondamentales d'introduction au machine learning
- **Level 2 - Intermediate**: Tâches de niveau intermédiaire avec des algorithmes plus complexes
- **Level 3 - Advanced**: Tâches avancées impliquant des modèles sophistiqués

## Niveaux et Tâches

### Level 1 - Basic
1. **Task 1 - Data Preprocessing**: Préparation et nettoyage des données avec visualisation, détection de valeurs aberrantes et matrices de confusion
2. **Task 2 - Linear Regression**: Régression linéaire simple
3. **Task 3 - KNN Classifier**: Classification avec l'algorithme des k plus proches voisins

### Level 2 - Intermediate
1. **Task 1 - Logistic Regression**: Régression logistique
2. **Task 2 - Decision Trees**: Arbres de décision
3. **Task 3 - KMeans Clustering**: Clustering avec l'algorithme KMeans

### Level 3 - Advanced
1. **Task 1 - Random Forest**: Forêts aléatoires
2. **Task 2 - Support Vector Machine**: Machines à vecteurs de support
3. **Task 3 - Neural Networks**: Réseaux de neurones

## Instructions

Chaque tâche contient :
- Un dossier `data/` pour les jeux de données
- Un notebook Jupyter ou script Python (.ipynb ou .py)
- Un fichier `README.md` décrivant la tâche et les résultats
- Un fichier `requirements.txt` listant les bibliothèques nécessaires (pour les tâches qui en ont besoin)

## Commencer

Pour exécuter les notebooks ou scripts, assurez-vous d'avoir installé toutes les dépendances requises :

```bash
pip install -r requirements.txt
```

Les bibliothèques sont spécifiées avec des versions minimales compatibles avec Python 3.13. Si vous utilisez une version plus ancienne de Python, vous pouvez ajuster les versions dans le fichier requirements.txt.
